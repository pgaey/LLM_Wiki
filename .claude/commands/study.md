# /study

주제: `$ARGUMENTS` (예: "클로저", "브라우저 렌더링 파이프라인", "OAuth 흐름")

## ⛩ 0. 대전제

1. **시작 시점에 reason 락** — Gold 게이트의 선제 적용. 이유 없으면 세션 시작 안 함.
2. **대화 자체가 소스**. 끝나면 자동으로 `raw/conversations/` 저장 → `/ingest synthesize` 체인.
3. **raw/ 는 불변**. 저장 후엔 본문 수정 금지 (프론트매터 status 만 예외).
4. AI는 **학습 유도자** — 정답을 즉시 불러주지 않고 **질문으로 유도**. "말로 설명 가능한 이해" 목표.
5. 위키 반영 시 [[WIKI_RULES]] 원칙 준수 (위키링크 basename, 파일명 규약, status).

## 🎯 1. 세션 오프닝

### 1A. Reason 질문 (🚪 게이트)
```
"[주제] 를 오늘 왜 공부하려는 거야? 한 줄로."
```
- **구체적 답변** (예: "렉시컬 스코프 이해", "면접 대비", "메모리 누수 디버깅용") → 4단계에서 저장.
- **"그냥 / 모르겠다"** → 세션 거부: *"지금 목적 불명확. 명확해지면 다시 호출."*

### 1B. 선행 지식 스캐닝
```
"이미 아는 부분 / 약한 부분?"
```
- 사용자 답 기반 예상 스텁 후보 미리 식별.
- 기존 `wiki/` 에 관련 페이지 있는지 확인 (Glob + Grep) → 있으면 기존 페이지 연결.

### 1C. 세션 목표 수준 확인
```
"오늘 세션 끝에 어느 수준까지?"
  a) 용어 정의 수준
  b) 메커니즘 이해 (어떻게 동작하는지)
  c) 30초 말로 설명 가능
  d) 실전 코드·상황으로 적용 가능
```

기본값: **c (30초 설명)**. d 선택 시 실습 예제 생성까지 포함.

## 🎓 2. 학습 대화 진행

### AI 행동 규칙
- **메커니즘·흐름 중심** 설명 (root CLAUDE.md 원칙).
- 정답 직불 금지 — 질문으로 유도: *"이 부분은 어떻게 동작할 것 같아?"*
- 낯선 용어 등장 시 **짧은 정의** 즉시 곁들임.
- 단계마다 **30초 설명 테스트**: *"방금 내용 너 말로 해볼래?"*
- 막힌 지점 발견 → **다음 학습 타겟**으로 별도 기록 (메모리만, 저장은 4단계).
- 사용자 1년 목표 리스트와 연결되는 순간 명시: *"이건 [[function-envy]]랑도 연결돼."*

### 옵션 분기 (플래그)
- `--source <URL>` 있으면: URL 내용을 먼저 fetch/파싱 → 그 위에서 대화.
- `--quick`: 10분 이내 세션 목표. 1~2개 핵심만.
- `--deep`: 2시간 세션, 하위 개념 여러 개 동시 다룸.

## ⏹ 3. 세션 종료 신호

사용자 신호 감지:
- 명시적: *"끝", "정리하자", "저장해줘", "충분"*
- 암시적: 주제가 자연스레 마무리되면 AI가 제안 — *"이쯤에서 정리할까?"*

종료 확정되면 4단계.

## 💾 4. 대화 저장 (자동)

### 4A. 대화 요약 구조화

`raw/conversations/YYYY-MM-DD-<영문-슬러그>.md` 로 저장. (파일명 규약: [[WIKI_RULES]] 섹션 4)

```markdown
---
source_type: conversation
title: "[주제]"
captured: YYYY-MM-DD
participants: ["user", "claude"]
reason: "<1A 답변>"
ingest_mode: synthesize
status: raw
tags: [study, <주제키워드>]
---

# [주제] — study session YYYY-MM-DD

## 📌 맥락
- **reason**: ...
- **선행 지식 (user)**: 아는 것 / 약한 것
- **세션 목표 수준**: a|b|c|d
- **참고 소스**: (--source 있으면 URL)

## 🔁 티키타카 (Q&A 요약)

### Q1. <AI 질문 or 논의 시작점>
**user**: ... (사용자 답 요약)
**claude**: ... (설명·정정 요약)
→ **이해 포인트**: ...
→ **막힌 지점**: ... (있을 경우)

### Q2. ...
(계속)

## 🧠 도달한 이해 (user 언어로 정리)
- (bullet: 핵심 주장·메커니즘·함정)

## 🆕 식별된 낯선 용어 / 다음 학습 타겟
- [[<용어-slug>]] — 정의 확정 필요
- [[<후속 개념>]] — 별도 소스 ingest 권장

## 🔗 관련 wiki 페이지
- [[<도메인/slug>]]
- ...
```

### 4B. `/ingest synthesize` 체인 자동 호출

저장 직후 `/ingest <그 파일>` 로 즉시 연결:
- 게이트 통과 (reason 이미 채움)
- 모드 자동 synthesize
- 타입별 질문 축: `source_type: conversation` 용 (→ `/ingest` 4C 표에 따라)
- `wiki/<domain>/` 스텁 생성 또는 기존 페이지 업데이트 (위키링크 `[[basename]]`)

### 4C. `wiki/log.md` 엔트리

```markdown
## [YYYY-MM-DD] study | <주제>
- 모드: study (자동 synthesize 체인)
- reason: <인용>
- 원본: [[raw-conversations-파일명]]
- 반영된 wiki: [[...]], [[...]]
- 식별된 스텁: [[...]]
- 다음 학습 타겟: [[...]]
```

## 📣 5. 마무리 보고

한 블록으로:
- ✅ 학습한 주제 · 세션 길이 (오프닝~종료)
- 📄 저장 위치: `raw/conversations/...`
- 🧱 업데이트된 wiki 페이지 (위키링크 리스트)
- 🎯 식별된 다음 학습 타겟
- 🔁 추천: **`/review <주제>`** 로 1일/3일/1주 뒤 복습 (미구현 시 "추후 구현 예정" 문구)

## 🔀 옵션 플래그 요약

- `/study <주제>` — 기본 세션
- `/study <주제> --source <URL>` — 블로그·문서 기반 대화
- `/study <주제> --quick` — 10분 이내, 깊이 얕음
- `/study <주제> --deep` — 2시간, 여러 하위 개념 동시

## 🚫 금지

- reason 없이 세션 진행 금지.
- 정답을 질문 없이 불러주는 것 금지 (학습 유도 위배).
- 저장 전 임의로 wiki 수정 금지 — `/ingest` 체인을 반드시 거친다.
- `raw/conversations/` 저장 후 본문 수정 금지.

---

## 🧾 참고

- `/study` 는 **`/ingest` 의 conversation 버전**. 출발점만 다르고 (blank 대화 vs raw 파일), 이후 파이프라인은 동일.
- 반복 재활용: 같은 주제 `/study <주제>` 다시 치면 → 기존 `raw/conversations/` 와 `wiki/<domain>/` 페이지 먼저 확인 → "이전 세션 있음, 이어서 할래 / 새로 할래?" 선택.
