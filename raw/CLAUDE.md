# raw/ — 불변 원본 레이어

> 이 폴더는 **소스 오브 트루스(Source of Truth)**다. AI는 읽기만 하고 **절대 수정·삭제하지 않는다**.

## 역할

사용자가 외부에서 수집한 원본 자료가 들어오는 곳. 클리핑·메모·영상 노트·업무 기록 등.
AI는 이것들을 읽어 `wiki/`에 지식으로 컴파일한다.

## 하위 폴더 용도

| 폴더 | 무엇을 넣는가 |
|------|------------|
| `articles/` | 웹 아티클, 블로그 포스트, 공식 문서 클리핑 (Obsidian Web Clipper 권장) |
| `videos/` | 유튜브·강의 영상 노트 (자막·요약·타임스탬프 메모) |
| `books/` | 책 챕터별 노트 |
| `work-notes/` | 업무 중 마주친 이슈·디버깅 1차 기록. 재가공 전 날것 그대로 |
| `conversations/` | AI 대화에서 건져낸 raw 지식 덩어리 |
| `assets/` | 이미지 등 첨부 파일 (Obsidian attachment 기본 경로) |

## 파일 네이밍 규칙 (권장)

`YYYY-MM-DD-제목-슬러그.md` 형태. 같은 날 여러 개면 접미사 `-01`, `-02`.

## 원본 파일 프론트매터 (권장)

```yaml
---
source_type: article | video | book | work | conversation
source_url: https://...
captured: 2026-04-12
tags: [react, async]
---
```

## AI 행동 규칙

1. **절대 금지**: `raw/` 하위 어떤 파일도 수정·삭제·이동하지 않는다.
2. **허용**: 읽기, 요약, 인용, 교차참조에 활용.
3. ingest 요청이 오면 이 폴더의 지정된 파일을 읽고 → `wiki/summaries/`에 요약 페이지를 생성한다.
4. 원본이 깨져 있거나(인코딩·링크) 정보가 부족해 보이면 **수정하지 말고 사용자에게 알린다**.
